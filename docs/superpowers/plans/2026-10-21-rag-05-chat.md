# RAG 对话接入实现计划（Stage 6）

> **For agentic workers:** 本文件覆盖 spec 的第 6 步。**前置事实：仓库里目前没有《AI对话思考链路API设计文档》的任何实现**（无 `SseEmitter`、无 `ai_conversation/ai_message`）。所以本阶段先补一个“对话最小闭环”，再接 RAG；最小闭环只实现 `meta → thought_step → delta → done` 与历史消息，不做 stop/断点续传/完整 reasoning 摘要。

**Goal:** 让 `POST /ai/chat/completions/stream` 的 `sources` 真正触发检索：`knowledge_base` / `question_bank` 走 `RetrievalService`，`attachment` 只报文件名；命中写 `ai_message_citation`，prompt 用 `[1]` 编号注入；ES 故障时降级为普通对话，不 500。

**Architecture:** `ChatStreamService` 负责编排（不直接碰 `SseEmitter`，事件通过 `Consumer<ChatEvent>` 输出，便于单测）；`ChatStreamController` 只负责 SSE 桥接。检索失败被 `RagChatContextService` 捕获并转成 `available=false`，编排层据此发“知识库不可用”并继续普通对话。引用在回答开始前落库（带定格快照），`meta_json.citations` 供前端角标。

**Tech Stack:** Spring MVC `SseEmitter` + Spring AI `ChatClient.stream()` + 现有 `RetrievalService` / `CitationWriter`。

**Spec:** `docs/superpowers/specs/2026-10-12-elasticsearch-rag-design.md`（第 5.6、7.3、7.4、7.5 节）与《AI对话思考链路API设计文档》第六、九节（事件契约、24 字符标题）。

## 最小对话闭环的范围（明确不做）

- 做：`POST /ai/chat/conversations`、`GET /ai/chat/conversations/{id}/messages`、`POST /ai/chat/completions/stream`、`POST /ai/chat/attachments`、`GET /ai/chat/models`。
- 不做：`/messages/{id}/stop`、`Last-Event-ID` 续流、DeepSeek `reasoning_content` 摘要、effort 三档的真实参数差异、会话重命名/删除/置顶。这些属于完整对话子系统，不影响 RAG 验收。
- `sources` 只认 `knowledge_base`、`question_bank`、`attachment` 三个值；其他值忽略并记日志。

```java
@Slf4j
@Service
public class ChatStreamService {

    private final ChatStreamer chatStreamer;
    private final AiConversationMapper conversationMapper;
    private final AiMessageMapper messageMapper;
    private final AiThoughtStepMapper stepMapper;
    private final EffortResolver effortResolver;
    private final RagChatContextService ragContextService;
    private final CitationWriter citationWriter;
    private final ObjectMapper objectMapper;

    public void stream(String userName, ChatStreamRequest request, Consumer<ChatEvent> sink) {
        Resolved resolved = effortResolver.resolve(request.getEffort());
        AiConversation conversation = ensureConversation(userName, request, resolved);
        AiMessage userMessage = insertMessage(conversation.getId(), "user", request.getContent(),
                "done", request.getClientMsgId());
        AiMessage assistant = insertMessage(conversation.getId(), "assistant", "", "streaming", null);

        sink.accept(new ChatEvent("meta", Map.of(
                "conversationId", conversation.getId(),
                "messageId", assistant.getId(),
                "modelKey", resolved.modelKey(),
                "effort", resolved.effort(),
                "supportsThinking", resolved.supportsThinking())));

        long retrievalStart = System.currentTimeMillis();
        RagChatContext rag = ragContextService.retrieve(
                userName, request.getContent(), request.getSources(), request.getAttachments());
        long retrievalMs = System.currentTimeMillis() - retrievalStart;

        List<AiMessageCitation> citations = citationWriter.write(
                assistant.getId(), conversation.getId(), rag);
        int seq = 1;
        for (RagThoughtStep step : rag.steps()) {
            stepMapper.insert(thoughtStep(assistant.getId(), seq++, step, retrievalMs));
            sink.accept(new ChatEvent("thought_step", Map.of(
                    "seq", seq - 1, "kind", "retrieval", "title", step.title(),
                    "refCount", step.refCount())));
        }
        sink.accept(new ChatEvent("thought_end", Map.of("seconds", retrievalMs / 1000.0)));

        String systemPrompt = ragContextService.systemPrompt(rag);
        StringBuilder answer = new StringBuilder();
        try {
            chatStreamer.stream(systemPrompt, request.getContent())
                    .doOnNext(text -> {
                        answer.append(text);
                        sink.accept(new ChatEvent("delta", Map.of("text", text)));
                    })
                    .blockLast();
            messageMapper.finish(assistant.getId(), answer.toString(), "done",
                    BigDecimal.valueOf(retrievalMs / 1000.0), citationsJson(rag));
            sink.accept(new ChatEvent("done", Map.of("finishReason", "stopped")));
        } catch (Exception e) {
            log.error("[Chat] 流式回答失败: {}", e.getMessage(), e);
            messageMapper.finish(assistant.getId(), answer.toString(), "failed",
                    BigDecimal.valueOf(retrievalMs / 1000.0), citationsJson(rag));
            sink.accept(new ChatEvent("error", Map.of("code", 0, "errorCode", "UPSTREAM_MODEL_ERROR",
                    "msg", "模型服务暂时不可用", "retryable", true)));
            sink.accept(new ChatEvent("done", Map.of("finishReason", "upstream")));
        }
        conversationMapper.updateLastMessage(conversation.getId(), assistant.getId());
    }
}
```

`ensureConversation`：无 `conversationId` 时新建，标题取 `content` 前 24 字符；有则校验 `user_name` 一致，否则抛“会话不存在”。`insertMessage` 在同一事务内写 user + assistant 两行；`uk_conv_client` 命中时直接返回既有用户消息（幂等）。

```java
@RestController
@RequestMapping("/ai/chat")
public class ChatStreamController {

    private final ChatStreamService service;
    private final ExecutorService executor = Executors.newFixedThreadPool(4);

    @PostMapping(value = "/completions/stream", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public SseEmitter stream(@RequestHeader("X-User-Name") String userName,
                             @Valid @RequestBody ChatStreamRequest request) {
        SseEmitter emitter = new SseEmitter(300_000L);
        executor.execute(() -> {
            try {
                service.stream(userName, request, event -> send(emitter, event));
                emitter.complete();
            } catch (Exception e) {
                try {
                    send(emitter, new ChatEvent("error", Map.of(
                            "code", 0, "msg", "服务内部错误", "retryable", true)));
                    send(emitter, new ChatEvent("done", Map.of("finishReason", "upstream")));
                    emitter.complete();
                } catch (Exception ignored) {
                    emitter.completeWithError(e);
                }
            }
        });
        emitter.onTimeout(emitter::complete);
        emitter.onError(e -> log.warn("[Chat] SSE 连接错误: {}", e.getMessage()));
        return emitter;
    }

    private void send(SseEmitter emitter, ChatEvent event) {
        try {
            // data 必须是单行 JSON
            emitter.send(SseEmitter.event().name(event.event())
                    .data(new ObjectMapper().writeValueAsString(event.data()),
                            MediaType.APPLICATION_JSON));
        } catch (Exception e) {
            throw new IllegalStateException("SSE 发送失败", e);
        }
    }
}
```

生产实现把 `ObjectMapper`/线程池作为 Bean 注入，线程池要有界并 `@PreDestroy` 关闭；`SseEmitter` 的 `send` 可能并发，`ChatStreamService` 是单线程逐事件调用，天然串行。

```java
@Service
public class RagChatContextService {

    private static final int TITLE_MAX = 24;

    private final RetrievalService retrievalService;
    private final AiAttachmentMapper attachmentMapper;
    private final RagProperties props;

    public RagChatContext retrieve(String userName, String content,
                                   List<String> sources, List<Long> attachmentIds) {
        if (sources == null || sources.isEmpty()) {
            return new RagChatContext(true, List.of(), List.of(), List.of(), List.of(), null);
        }
        List<KnowledgeSearchItem> kb = new ArrayList<>();
        List<QuestionSearchItem> questions = new ArrayList<>();
        List<String> attachments = new ArrayList<>();
        List<RagThoughtStep> steps = new ArrayList<>();
        try {
            if (sources.contains("knowledge_base")) {
                KnowledgeSearchResponse response = retrievalService.searchKnowledge(content,
                        new SearchOptions(userName, List.of("official", "personal"), null,
                                props.getSearch().getTopKDefault()));
                kb.addAll(response.items());
                steps.add(new RagThoughtStep(truncate("检索知识库 · 命中 " + kb.size() + " 条"),
                        kb.size()));
            }
            if (sources.contains("question_bank")) {
                QuestionSearchResponse response = retrievalService.searchQuestions(content,
                        new SearchOptions(userName, List.of("official", "personal"), null, 3));
                questions.addAll(response.items());
                steps.add(new RagThoughtStep(truncate("检索题库 · 命中 " + questions.size() + " 条"),
                        questions.size()));
            }
            if (sources.contains("attachment") && attachmentIds != null) {
                for (Long id : attachmentIds) {
                    AiAttachment attachment = attachmentMapper.selectById(id);
                    if (attachment != null && userName.equals(attachment.getUserName())) {
                        attachments.add(attachment.getName());
                    }
                }
                steps.add(new RagThoughtStep(truncate("读取附件 " + String.join("、", attachments)),
                        attachments.size()));
            }
            return new RagChatContext(true, kb, questions, attachments, steps, null);
        } catch (Exception e) {
            // 检索是增强不是依赖：ES 挂了聊天仍要继续
            log.warn("[RAG] 检索失败，降级为普通对话: {}", e.getMessage());
            return new RagChatContext(false, List.of(), List.of(), List.of(),
                    List.of(new RagThoughtStep("知识库不可用", 0)), e.getMessage());
        }
    }

    private String truncate(String title) {
        return title.length() <= TITLE_MAX ? title : title.substring(0, TITLE_MAX - 1) + "…";
    }
}
```

```java
public String systemPrompt(RagChatContext context) {
    if (!context.available()) {
        return "你是教材考点知识库问答助手。知识库暂时不可用，请基于你自己的知识回答，"
                + "并明确告知学生本次回答没有教材依据。";
    }
    if (context.kbHits().isEmpty() && context.questionHits().isEmpty()) {
        return "你是教材考点知识库问答助手。知识库中未检索到相关内容，请基于你自己的知识回答，"
                + "并明确告知学生没有教材依据。不要编造引用。";
    }
    StringBuilder sb = new StringBuilder("你是教材考点知识库问答助手。以下是与问题相关的教材片段与题库：\n");
    int ref = 1;
    for (KnowledgeSearchItem hit : context.kbHits()) {
        sb.append("[").append(ref++).append("]（")
          .append(nullToEmpty(hit.book())).append(" 第").append(hit.pageNo()).append("页，")
          .append(nullToEmpty(hit.chapterPath())).append("）\n")
          .append(hit.content()).append("\n");
    }
    for (QuestionSearchItem q : context.questionHits()) {
        sb.append("[Q").append(q.questionId()).append("] ").append(q.title()).append("\n");
    }
    sb.append("回答要求：只使用与问题相关的片段；引用教材时用 [n] 标注；")
```

```java
@Service
public class CitationWriter {

    private final AiMessageCitationMapper mapper;

    public List<AiMessageCitation> write(long messageId, long conversationId,
                                         RagChatContext context) {
        List<AiMessageCitation> result = new ArrayList<>();
        int rank = 1;
        for (KnowledgeSearchItem hit : context.kbHits()) {
            AiMessageCitation citation = new AiMessageCitation();
            citation.setMessageId(messageId);
            citation.setConversationId(conversationId);
            citation.setChunkId(hit.chunkId());          // 知识库命中：非 0
            citation.setQuestionId(0L);                  // 二选一：必须写 0，不能 null
            citation.setIndexName("ai_kb_chunk");
            citation.setRank(rank++);
            citation.setCosine(BigDecimal.valueOf(hit.cosine()).setScale(5, RoundingMode.HALF_UP));
            citation.setBook(nullToEmpty(hit.book()));
            citation.setChapterPath(nullToEmpty(hit.chapterPath()));
            citation.setPageNo(hit.pageNo() == null ? 0 : hit.pageNo());
            citation.setSnapshotTitle(nullToEmpty(hit.title()));
            mapper.insert(citation);
            result.add(citation);
        }
        for (QuestionSearchItem hit : context.questionHits()) {
            AiMessageCitation citation = new AiMessageCitation();
            citation.setMessageId(messageId);
            citation.setConversationId(conversationId);
            citation.setChunkId(0L);                     // 题库命中：chunk_id 必须写 0
            citation.setQuestionId(hit.questionId());
            citation.setIndexName("ai_question");
            citation.setRank(rank++);
            citation.setCosine(BigDecimal.valueOf(hit.cosine()).setScale(5, RoundingMode.HALF_UP));
            citation.setBook("");
            citation.setChapterPath("");
            citation.setPageNo(0);
            citation.setSnapshotTitle(nullToEmpty(hit.title()));
            mapper.insert(citation);
            result.add(citation);
        }
        return result;
    }
}
```
