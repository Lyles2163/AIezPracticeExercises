# 上传自动录题实现计划（Stage 7）

> **For agentic workers:** 本文件覆盖 spec 的第 7 步。前置条件：Stage 4a 已建 `ai_extract_draft`；Stage 5 的 `QuestionIndexService` 可用。

**Goal:** 上传一份试卷/习题文档 → 解析文本 → DeepSeek 结构化抽取题目 → 写入 `ai_extract_draft` 待审 → 人工 approve/reject → approve 直接 INSERT `qb_question` 并触发单题索引。

**Architecture:** 抽取复用 `DocParser` 与 `ChunkPlanner`（按 12000 字符切批，避免超出模型上下文）；`ChatClient.call().entity(ExtractResult.class)` 让 Spring AI 负责格式说明与 JSON 解析。草稿表独立，`qb_question.status` 仍是上架/下架语义，不混入 AI 状态。审核通过后 `QuestionIndexService.createFromDraft` 是唯一写 `qb_question` 的入口，事务提交后再建索引。

**Tech Stack:** Spring AI `ChatClient.entity()`、现有 `DocParser`、`ai_extract_draft`、`QuestionIndexService`。

**Spec:** `docs/superpowers/specs/2026-10-12-elasticsearch-rag-design.md`（第 2.1、4.2 ⑤、5.5、7.1 节）

---

## 范围与约定

- 任务标识：spec 说 `POST /ai/extract/tasks` 返回 `taskId`，但没有定义任务表。本实现返回 `docId` 作为 `taskId`，进度看该文档的草稿列表；不新增表。
- 重抽取限制：同一文档如果已有 `converted` 草稿，拒绝重新抽取（避免 `uk_doc_raw` 冲突与重复题目）。只有 `pending/rejected` 时可以重跑；重跑前删除该文档所有非 converted 草稿。
- 抽取只做文本题，不做图片/公式 OCR；解析不出文本的文档在 Stage 4a 已被拒收。
- `ai_extract_draft.status` 只有 `pending / converted / rejected`，**没有 approved**。

            1. 只输出 JSON，不要 Markdown 代码块，不要解释。

```java
@Service
@Slf4j
public class ExtractService {

    private static final int MAX_CHARS_PER_CALL = 12_000;

    private final AiKbDocMapper docMapper;
    private final AiExtractDraftMapper draftMapper;
    private final DocParser docParser;
    private final StorageService storageService;
    private final ChatClient chatClient;
    private final ObjectMapper objectMapper;
    private final ExtractDraftPersistenceService draftPersistence;
    private final ExtractTaskDispatcher dispatcher;

    public void run(long docId, Long subjectId, String operator) {
        AiKbDoc doc = docMapper.selectById(docId);
        if (doc == null || "deleted".equals(doc.getStatus())) {
            throw new RagException("文档不存在: " + docId);
        }
        if (draftMapper.countConverted(docId) > 0) {
            throw new RagException("该文档已有已转换的草稿，不能重新抽取");
        }

        ParsedDoc parsed;
        try {
            parsed = docParser.parse(storageService.open(doc.getStorageKey()),
                    doc.getFileName(), doc.getMime());
        } catch (IOException e) {
            throw new RagException("文档解析失败: " + e.getMessage(), e);
        }
        String text = parsed.pages().stream()
                .map(p -> "【第" + p.pageNo() + "页】\n" + p.text())
                .collect(Collectors.joining("\n\n"));
        List<String> batches = split(text, MAX_CHARS_PER_CALL);
        List<ExtractedQuestion> questions = new ArrayList<>();
        for (String batch : batches) {
            ExtractResult result = chatClient.prompt()
                    .system(ExtractPrompt.SYSTEM)
                    .user("请从以下文本中抽取题目：\n\n" + batch)
                    .call()
                    .entity(ExtractResult.class);
            if (result != null && result.getQuestions() != null) {
                questions.addAll(result.getQuestions());
            }
        }
        questions = dedupe(questions);
        if (questions.isEmpty()) {
            throw new RagException("未抽取到题目，请确认文档内容");
        }
        draftPersistence.saveDrafts(docId, subjectId, operator, questions);
        log.info("[RAG] 文档 {} 抽取完成，草稿 {} 条", docId, questions.size());
    }

    public long submit(long docId, Long subjectId, String operator) {
        AiKbDoc doc = docMapper.selectById(docId);
        if (doc == null || "deleted".equals(doc.getStatus())) {
            throw new RagException("文档不存在: " + docId);
        }
        if (draftMapper.countConverted(docId) > 0) {
            throw new RagException("该文档已有已转换的草稿，不能重新抽取");
        }
        dispatcher.dispatch(new ExtractTask(docId, subjectId, operator));
        return docId;
    }

    private List<String> split(String text, int maxChars) {
        List<String> batches = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        for (String paragraph : text.split("\\R\\s*\\R")) {
            if (paragraph.isBlank()) {
                continue;
            }
            if (paragraph.length() > maxChars) {
                if (current.length() > 0) {
                    batches.add(current.toString());
                    current.setLength(0);
                }
                for (int from = 0; from < paragraph.length(); from += maxChars) {
                    batches.add(paragraph.substring(from,
                            Math.min(from + maxChars, paragraph.length())));
                }
                continue;
            }
            if (current.length() > 0 && current.length() + paragraph.length() > maxChars) {
                batches.add(current.toString());
                current.setLength(0);
            }
            current.append(paragraph).append("\n\n");
        }
        if (current.length() > 0) {
            batches.add(current.toString());
        }
        return batches;
    }

    private List<ExtractedQuestion> dedupe(List<ExtractedQuestion> questions) {
        Map<String, ExtractedQuestion> unique = new LinkedHashMap<>();
        for (ExtractedQuestion question : questions) {
            if (question.getTitle() == null || question.getTitle().isBlank()) {
                continue;
            }
            unique.putIfAbsent(question.getTitle().strip().replaceAll("\\s+", ""), question);
        }
        return new ArrayList<>(unique.values());
    }
}
```

构造器注入上面所有依赖；`dispatcher` 按 `rag.async` 注入 `PollExtractDispatcher` 或 `MqExtractDispatcher`。

`saveDrafts` 必须放在独立 Bean：`ExtractService` 内 `this.saveDrafts(...)` 不会经过 Spring 代理，`@Transactional` 会静默失效。`ExtractService` 注入并调用 `draftPersistence.saveDrafts(docId, subjectId, operator, questions)`。

```java
package org.leon.aimodule.rag.extract;

import com.fasterxml.jackson.databind.ObjectMapper;
import org.leon.aimodule.rag.entity.AiExtractDraft;
import org.leon.aimodule.rag.mapper.AiExtractDraftMapper;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.util.List;

@Service
public class ExtractDraftPersistenceService {

    private final AiExtractDraftMapper draftMapper;
    private final ObjectMapper objectMapper;

    public ExtractDraftPersistenceService(AiExtractDraftMapper draftMapper, ObjectMapper objectMapper) {
        this.draftMapper = draftMapper;
        this.objectMapper = objectMapper;
    }

    @Transactional
    public void saveDrafts(long docId, Long subjectId, String operator,
                           List<ExtractedQuestion> questions) {
        draftMapper.deleteNonConvertedByDoc(docId);
        int index = 1;
        for (ExtractedQuestion q : questions) {
            AiExtractDraft draft = new AiExtractDraft();
            draft.setDocId(docId);
            draft.setRawIndex(index++);
            draft.setQtype(normalizeQtype(q.getQtype()));
            draft.setTitle(q.getTitle());
            draft.setOptionsJson(json(q.getOptions()));
            draft.setAnswerJson(q.getAnswer() == null ? "{}" : json(q.getAnswer()));
            draft.setAnalysis(q.getAnalysis());
            draft.setTagsJson(json(q.getTags() == null ? List.of() : q.getTags()));
            draft.setSubjectId(subjectId);
            draft.setDifficulty(q.getDifficulty());
            draft.setModelKey("deepseek-chat");
            draft.setPromptVersion(ExtractPrompt.VERSION);
            draft.setStatus("pending");
            draftMapper.insert(draft);
        }
    }

    private String normalizeQtype(String qtype) {
        return switch (qtype == null ? "" : qtype) {
            case "single", "multi", "blank", "judge", "short" -> qtype;
            default -> "short";
        };
    }

    private String json(Object value) {
        try {
            return objectMapper.writeValueAsString(value == null ? List.of() : value);
        } catch (Exception e) {
            return "[]";
        }
    }
}
```

```java
@Transactional
public ReviewResult review(long draftId, String reviewer, ReviewRequest request) {
    AiExtractDraft draft = draftMapper.selectById(draftId);
    if (draft == null || !"pending".equals(draft.getStatus())) {
        throw new RagException("草稿不存在或已审核");
    }
    if ("reject".equals(request.decision())) {
        draftMapper.markRejected(draftId, reviewer, request.reason());
        return new ReviewResult(draftId, 0, "rejected");
    }
    if (!"approve".equals(request.decision())) {
        throw new RagException("decision 只能是 approve 或 reject");
    }
    applyPatch(draft, request.patch());
    long ownerId = resolveOwnerId(draft); // official 文档 -> 1；personal -> users_dev.id
    long questionId = questionIndexService.createFromDraft(draft, ownerId);
    draftMapper.markConverted(draftId, questionId, reviewer);
    TransactionSynchronizationManager.registerSynchronization(new TransactionSynchronization() {
        @Override
        public void afterCommit() {
            try {
                questionIndexService.indexQuestion(questionId);
            } catch (Exception e) {
                log.warn("[RAG] 新题 {} 建索引失败，稍后由回灌作业补: {}", questionId, e.getMessage());
            }
        }
    });
    return new ReviewResult(draftId, questionId, "converted");
}
```

`resolveOwnerId`：
- `draft.docId > 0` 时查 `ai_kb_doc`：
  - official → `1`
  - personal → `SELECT id FROM users_dev WHERE username = ?`
- `docId=0`（手工草稿）→ 审核人对应的 `users_dev.id`。

`patch` 允许改 `title/analysis/answer/options/tags/subjectId/difficulty`；改完序列化回草稿的 JSON 列，再 insert `qb_question`。

## 自动录题验收清单（Stage 7）

- [ ] 5 题 docx → 5 条草稿，`raw_index` 连续，五种题型正确。
- [ ] 模型没给答案时 `answer_json={}`，不编造。
- [ ] approve 后 `qb_question` 新增、`draft` 置 `converted` 并回填 `question_id`。
- [ ] approve 后单题索引生效：自然语言能搜到新题。
