# RAG MQ 派发实现计划（Stage 4b）

> **For agentic workers:** 本文件覆盖 spec 的第 4b 步。前置条件：Stage 4a 已验收（poll 模式能跑通）；RabbitMQ 4.3.6 在 5672/15672 运行（guest/guest 仅回环）。

**Goal:** 把入库触发从“定时扫 pending”升级为“事务提交后发消息 + 手动 ack 消费”，并保留 `poll` 扫描作为兜底。失败消息按 30 秒 → 2 分钟 → 10 分钟三级 TTL 退避，第四次失败进 DLQ，提供 DLQ 查看与重投接口。

**Architecture:** `ai.topic` 是主交换机，`ai.retry` 是重试交换机；三个重试队列各自 TTL 不同、DLX 指回 `ai.topic`，因此消息过期后保留**原 routing key** 自动回到对应主队列。消费者手动 ack：成功 ack；失败先发布到下一级重试队列再 ack；发布失败则拒绝并进 `ai.dlq`。MySQL 状态机与 CAS 抢占完全复用 4a，不因 MQ 改动。

**Tech Stack:** Spring AMQP 3.1.x / RabbitMQ 4.3.6 / Jackson JSON 消息转换。

**Spec:** `docs/superpowers/specs/2026-10-12-elasticsearch-rag-design.md`（第 2.5、5.7、7.5 节）

---

## 关键偏差说明（执行前必读）

1. **spec 说“异常 `nack(requeue=false)` 让它进 retry 队列”**。固定队列的 DLX 只能指向固定目标，无法在 30s/2m/10m 三级之间切换。本计划改为“消费者捕获异常 → 发布到下一级重试队列 → ack”，效果等价且能实现分级退避；消息仍是 at-least-once，幂等由 CAS + 同 `_id` 覆盖写兜住。
2. **重试队列按“原 routing key”绑定到 `ai.retry`**。消息以原 routing key 发布到 `ai.retry`，TTL 到期后 DLX 回 `ai.topic` 时仍保留原 routing key，因此一条重试队列可以服务 `ai.kb.ingest` / `ai.question.index` / `ai.extract.run` 三种任务，不需要为每种任务建 9 个队列。
3. **主队列的 DLX 是 `ai.dlq.exchange`，不是 `ai.retry`**。如果把主队列 DLX 指向 `ai.retry`，容器拒绝一条消息会同时命中三个 TTL 队列，产生三份重复。重试由消费者代码显式发布；DLX 只用于“代码本身失败”的兜底。

```java
package org.leon.aimodule.rag.mq;

import org.springframework.amqp.core.Binding;
import org.springframework.amqp.core.BindingBuilder;
import org.springframework.amqp.core.DirectExchange;
import org.springframework.amqp.core.Queue;
import org.springframework.amqp.core.QueueBuilder;
import org.springframework.amqp.core.TopicExchange;
import org.springframework.amqp.support.converter.Jackson2JsonMessageConverter;
import org.springframework.amqp.support.converter.MessageConverter;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import com.fasterxml.jackson.databind.ObjectMapper;

@Configuration
public class RagMqConfig {

    public static final String TOPIC_EXCHANGE = "ai.topic";
    public static final String RETRY_EXCHANGE = "ai.retry";
    public static final String DLQ_EXCHANGE = "ai.dlq.exchange";
    public static final String DLQ = "ai.dlq";

    public static final String KB_INGEST_KEY = "ai.kb.ingest";
    public static final String QUESTION_INDEX_KEY = "ai.question.index";
    public static final String EXTRACT_KEY = "ai.extract.run";
    public static final String DLQ_KEY = "ai.dlq";

    public static final String KB_INGEST_QUEUE = "ai.kb.ingest";
    public static final String QUESTION_INDEX_QUEUE = "ai.question.index";
    public static final String EXTRACT_QUEUE = "ai.extract.run";

    public static final String RETRY_30S = "ai.retry.30s";
    public static final String RETRY_2M = "ai.retry.2m";
    public static final String RETRY_10M = "ai.retry.10m";

    @Bean
    public TopicExchange aiTopicExchange() {
        return new TopicExchange(TOPIC_EXCHANGE, true, false);
    }

    @Bean
    public TopicExchange aiRetryExchange() {
        return new TopicExchange(RETRY_EXCHANGE, true, false);
    }

    @Bean
    public DirectExchange aiDlqExchange() {
        return new DirectExchange(DLQ_EXCHANGE, true, false);
    }

    @Bean
    public Queue kbIngestQueue() {
        return QueueBuilder.durable(KB_INGEST_QUEUE)
                .deadLetterExchange(DLQ_EXCHANGE)
                .deadLetterRoutingKey(DLQ_KEY)
                .build();
    }

    @Bean
    public Queue questionIndexQueue() {
        return QueueBuilder.durable(QUESTION_INDEX_QUEUE)
                .deadLetterExchange(DLQ_EXCHANGE)
                .deadLetterRoutingKey(DLQ_KEY)
                .build();
    }

    @Bean
    public Queue extractQueue() {
        return QueueBuilder.durable(EXTRACT_QUEUE)
                .deadLetterExchange(DLQ_EXCHANGE)
                .deadLetterRoutingKey(DLQ_KEY)
                .build();
    }

    @Bean
    public Queue dlq() {
        return QueueBuilder.durable(DLQ).build();
    }

    @Bean
    public Queue retry30s() {
        return retryQueue(RETRY_30S, 30_000);
    }

    @Bean
    public Queue retry2m() {
        return retryQueue(RETRY_2M, 120_000);
    }

    @Bean
    public Queue retry10m() {
        return retryQueue(RETRY_10M, 600_000);
    }

    private Queue retryQueue(String name, int ttlMillis) {
        // 不指定 dead-letter-routing-key：保留消息发布时的原 routing key，过期后回到对应主队列
        return QueueBuilder.durable(name)
                .ttl(ttlMillis)
                .deadLetterExchange(TOPIC_EXCHANGE)
                .build();
    }

    @Bean
    public Binding kbIngestBinding() {
        return BindingBuilder.bind(kbIngestQueue()).to(aiTopicExchange()).with(KB_INGEST_KEY);
    }

    @Bean
    public Binding questionIndexBinding() {
        return BindingBuilder.bind(questionIndexQueue()).to(aiTopicExchange()).with(QUESTION_INDEX_KEY);
    }

    @Bean
    public Binding extractBinding() {
        return BindingBuilder.bind(extractQueue()).to(aiTopicExchange()).with(EXTRACT_KEY);
    }

    @Bean
    public Binding dlqBinding() {
        return BindingBuilder.bind(dlq()).to(aiDlqExchange()).with(DLQ_KEY);
    }

    @Bean
    public Binding retry30sKbBinding() {
        return BindingBuilder.bind(retry30s()).to(aiRetryExchange()).with(KB_INGEST_KEY);
    }

    @Bean
    public Binding retry30sQuestionBinding() {
        return BindingBuilder.bind(retry30s()).to(aiRetryExchange()).with(QUESTION_INDEX_KEY);
    }

    @Bean
    public Binding retry30sExtractBinding() {
        return BindingBuilder.bind(retry30s()).to(aiRetryExchange()).with(EXTRACT_KEY);
    }

    @Bean
    public Binding retry2mKbBinding() {
        return BindingBuilder.bind(retry2m()).to(aiRetryExchange()).with(KB_INGEST_KEY);
    }

    @Bean
    public Binding retry2mQuestionBinding() {
        return BindingBuilder.bind(retry2m()).to(aiRetryExchange()).with(QUESTION_INDEX_KEY);
    }

    @Bean
    public Binding retry2mExtractBinding() {
        return BindingBuilder.bind(retry2m()).to(aiRetryExchange()).with(EXTRACT_KEY);
    }

    @Bean
    public Binding retry10mKbBinding() {
        return BindingBuilder.bind(retry10m()).to(aiRetryExchange()).with(KB_INGEST_KEY);
    }

    @Bean
    public Binding retry10mQuestionBinding() {

    }
```

```java
import com.fasterxml.jackson.databind.JsonNode;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.junit.jupiter.api.BeforeEach;

import org.junit.jupiter.api.Tag;

import org.springframework.boot.test.context.SpringBootTest;

import java.net.http.HttpResponse;
import java.nio.charset.StandardCharsets;
import java.util.Base64;

import static org.junit.jupiter.api.Assertions.assertEquals;
import static org.junit.jupiter.api.Assertions.assertTrue;

@Tag("mq-it")
@SpringBootTest
class RagMqTopologyTest {

    private static final String MGMT = "http://127.0.0.1:15672/api";
    private static final String VHOST = "%2F";

    @Autowired
    private RabbitAdmin rabbitAdmin;

    @Autowired
    private ObjectMapper objectMapper;

    @BeforeEach
    void declare() {
        rabbitAdmin.initialize();
    }

    private JsonNode get(String path) throws Exception {
        HttpRequest request = HttpRequest.newBuilder(URI.create(MGMT + path))
                .header("Authorization", "Basic " + Base64.getEncoder()
                        .encodeToString("guest:guest".getBytes(StandardCharsets.UTF_8)))
                .GET().build();
        HttpResponse<String> response = HttpClient.newHttpClient()
                .send(request, HttpResponse.BodyHandlers.ofString());
        assertEquals(200, response.statusCode(), response.body());
        return objectMapper.readTree(response.body());
    }

    @Test
    @DisplayName("三级重试队列的 TTL 与 DLX 正确")
    void retryQueuesHaveTtlAndDlx() throws Exception {
        JsonNode q30 = get("/queues/" + VHOST + "/" + RagMqConfig.RETRY_30S);
        assertEquals(30000, q30.path("arguments").path("x-message-ttl").asInt());
        assertEquals(RagMqConfig.TOPIC_EXCHANGE,
                q30.path("arguments").path("x-dead-letter-exchange").asText());
        assertTrue(q30.path("arguments").path("x-dead-letter-routing-key").isMissingNode(),

        JsonNode q2m = get("/queues/" + VHOST + "/" + RagMqConfig.RETRY_2M);
        assertEquals(120000, q2m.path("arguments").path("x-message-ttl").asInt());
        JsonNode q10m = get("/queues/" + VHOST + "/" + RagMqConfig.RETRY_10M);
        assertEquals(600000, q10m.path("arguments").path("x-message-ttl").asInt());
    }

    @Test
    @DisplayName("主队列绑定在 ai.topic 上，且 DLX 指向死信交换机")
    void mainQueuesAreBound() throws Exception {
        JsonNode bindings = get("/exchanges/" + VHOST + "/" + RagMqConfig.TOPIC_EXCHANGE + "/bindings/source");
        String text = bindings.toString();
        assertTrue(text.contains(RagMqConfig.KB_INGEST_QUEUE));
        assertTrue(text.contains(RagMqConfig.QUESTION_INDEX_QUEUE));
        assertTrue(text.contains(RagMqConfig.EXTRACT_QUEUE));

        JsonNode queue = get("/queues/" + VHOST + "/" + RagMqConfig.KB_INGEST_QUEUE);
        assertEquals(RagMqConfig.DLQ_EXCHANGE,
                queue.path("arguments").path("x-dead-letter-exchange").asText());
    }
}
```

```java
package org.leon.aimodule.rag.mq;

import lombok.extern.slf4j.Slf4j;
import org.springframework.amqp.core.MessageDeliveryMode;
import org.springframework.amqp.rabbit.core.RabbitTemplate;
import org.springframework.stereotype.Component;

@Slf4j
@Component
public class RagRetryPublisher {

    private static final int MAX_RETRIES = 3;

    private final RabbitTemplate rabbitTemplate;

    public RagRetryPublisher(RabbitTemplate rabbitTemplate) {
        this.rabbitTemplate = rabbitTemplate;
    }

    public void retryOrDead(String routingKey, Object payload, Integer retryCount, Exception error) {
        int attempt = retryCount == null ? 0 : retryCount;
        if (attempt >= MAX_RETRIES) {
            rabbitTemplate.convertAndSend(RagMqConfig.DLQ_EXCHANGE, RagMqConfig.DLQ_KEY, payload, message -> {
                message.getMessageProperties().setHeader("x-original-routing-key", routingKey);
                message.getMessageProperties().setHeader("x-retry-count", attempt);
                message.getMessageProperties().setHeader("x-last-error", truncate(error.getMessage()));
                message.getMessageProperties().setDeliveryMode(MessageDeliveryMode.PERSISTENT);
                return message;
            });
            log.error("[RAG] 消息重试耗尽，进入死信: routingKey={} retryCount={}", routingKey, attempt);
            return;
        }

        String retryQueue = switch (attempt) {
            case 0 -> RagMqConfig.RETRY_30S;
            case 1 -> RagMqConfig.RETRY_2M;
            default -> RagMqConfig.RETRY_10M;
        };
        int next = attempt + 1;
        rabbitTemplate.convertAndSend(RagMqConfig.RETRY_EXCHANGE, routingKey, payload, message -> {
            message.getMessageProperties().setHeader("x-retry-count", next);
            message.getMessageProperties().setHeader("x-last-error", truncate(error.getMessage()));
            message.getMessageProperties().setDeliveryMode(MessageDeliveryMode.PERSISTENT);
            return message;
        });
        log.warn("[RAG] 消息第 {} 次失败，{} 后重试: routingKey={}", next, retryQueue, routingKey);
    }

    private String truncate(String text) {
        if (text == null) {
            return "";
        }
        return text.length() <= 200 ? text : text.substring(0, 200);
    }
}
```

```java
package org.leon.aimodule.rag.mq;

import com.rabbitmq.client.Channel;
import lombok.extern.slf4j.Slf4j;
import org.leon.aimodule.rag.ingest.IngestService;
import org.leon.aimodule.rag.ingest.IngestTask;
import org.springframework.amqp.core.AmqpHeaders;
import org.springframework.amqp.rabbit.annotation.RabbitListener;
import org.springframework.messaging.handler.annotation.Header;
import org.springframework.stereotype.Component;

import java.io.IOException;

@Slf4j
@Component
public class KbIngestConsumer {

    private final IngestService ingestService;
    private final RagRetryPublisher retryPublisher;

    public KbIngestConsumer(IngestService ingestService, RagRetryPublisher retryPublisher) {
        this.ingestService = ingestService;
        this.retryPublisher = retryPublisher;
    }

    @RabbitListener(queues = RagMqConfig.KB_INGEST_QUEUE,
            containerFactory = RagListenerConfig.MANUAL_ACK_FACTORY)
    public void onIngest(IngestTask task, Channel channel,
                         @Header(AmqpHeaders.DELIVERY_TAG) long deliveryTag,
                         @Header(value = "x-retry-count", required = false) Integer retryCount,
                         @Header(AmqpHeaders.RECEIVED_ROUTING_KEY) String routingKey) throws IOException {
        try {
            ingestService.process(task.docId());
            channel.basicAck(deliveryTag, false);
        } catch (Exception e) {
            log.error("[RAG] 消费文档 {} 失败: {}", task.docId(), e.getMessage(), e);
            try {
                retryPublisher.retryOrDead(routingKey, task, retryCount, e);
                channel.basicAck(deliveryTag, false);
            } catch (Exception publishError) {
                // 重试消息都发不出去：拒绝并交给主队列 DLX 进死信
                log.error("[RAG] 发布重试消息失败，消息转入死信: {}", publishError.getMessage());
                channel.basicNack(deliveryTag, false, false);
            }
        }
    }
}
```

```java
package org.leon.aimodule.rag.mq;

import org.springframework.amqp.core.AcknowledgeMode;

import org.springframework.amqp.support.converter.MessageConverter;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class RagListenerConfig {

    public static final String MANUAL_ACK_FACTORY = "ragManualAckFactory";
    public static final String QUESTION_FACTORY = "ragQuestionFactory";

    @Bean(name = MANUAL_ACK_FACTORY)
    public SimpleRabbitListenerContainerFactory manualAckFactory(
            ConnectionFactory connectionFactory, MessageConverter converter,
            @Value("${rag.mq.ingest-prefetch:1}") int prefetch) {
        SimpleRabbitListenerContainerFactory factory = new SimpleRabbitListenerContainerFactory();
        factory.setConnectionFactory(connectionFactory);
        factory.setMessageConverter(converter);
        factory.setAcknowledgeMode(AcknowledgeMode.MANUAL);
        factory.setPrefetchCount(prefetch);
        factory.setDefaultRequeueRejected(false);
        return factory;
    }

            ConnectionFactory connectionFactory, MessageConverter converter,

        factory.setConnectionFactory(connectionFactory);
        factory.setMessageConverter(converter);
        factory.setAcknowledgeMode(AcknowledgeMode.MANUAL);
        factory.setPrefetchCount(prefetch);
        factory.setDefaultRequeueRejected(false);
        return factory;
    }
```

- [ ] **Step 1: 写服务（basicGet + requeue 读取；重投时 ack）**

```java
package org.leon.aimodule.rag.mq;

import com.rabbitmq.client.GetResponse;
import lombok.extern.slf4j.Slf4j;
import org.leon.aimodule.rag.ingest.IngestTask;
import org.leon.aimodule.rag.mapper.AiKbDocMapper;
import org.springframework.amqp.rabbit.core.RabbitTemplate;
import org.springframework.stereotype.Service;

import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;

@Slf4j
@Service
public class DlqAdminService {

    private final RabbitTemplate rabbitTemplate;
    private final AiKbDocMapper docMapper;

    public DlqAdminService(RabbitTemplate rabbitTemplate, AiKbDocMapper docMapper) {
        this.rabbitTemplate = rabbitTemplate;
        this.docMapper = docMapper;
    }

    public List<DlqItem> list(int limit) {
        return rabbitTemplate.execute(channel -> {
            List<DlqItem> items = new ArrayList<>();
            long count = channel.messageCount(RagMqConfig.DLQ);
            int read = (int) Math.min(count, Math.max(1, limit));
            for (int i = 0; i < read; i++) {
                GetResponse response = channel.basicGet(RagMqConfig.DLQ, false);
                if (response == null) {
                    break;
                }
                long tag = response.getEnvelope().getDeliveryTag();
                try {
                    String body = new String(response.getBody(), StandardCharsets.UTF_8);
                    IngestTask task = parse(body);
                    String routingKey = header(response, "x-original-routing-key");
                    Integer retryCount = intHeader(response, "x-retry-count");
                    String lastError = header(response, "x-last-error");
                    items.add(new DlqItem(routingKey, task == null ? 0 : task.docId(),
                            retryCount == null ? 0 : retryCount, lastError));
                } finally {
                    // 只读不改：放回队列
                    channel.basicNack(tag, false, true);
                }
            }
            return items;
        });
    }

    public int replay(String routingKey, List<Long> docIds) {
        return rabbitTemplate.execute(channel -> {
            int replayed = 0;
            long count = channel.messageCount(RagMqConfig.DLQ);
            for (int i = 0; i < count; i++) {
                GetResponse response = channel.basicGet(RagMqConfig.DLQ, false);
                if (response == null) {
                    break;
                }
                long tag = response.getEnvelope().getDeliveryTag();
                IngestTask task = parse(new String(response.getBody(), StandardCharsets.UTF_8));
                String originalKey = header(response, "x-original-routing-key");
                boolean match = task != null && docIds.contains(task.docId())
                        && (routingKey == null || routingKey.isBlank() || routingKey.equals(originalKey));
                if (!match) {
                    channel.basicNack(tag, false, true);
                    continue;
                }
                // 死信里 retry_count 已是 3，必须归零，否则消费者抢到后立刻被回收扫描判死
                docMapper.resetRetryCount(task.docId());
                rabbitTemplate.convertAndSend(RagMqConfig.TOPIC_EXCHANGE, originalKey, task);
                channel.basicAck(tag, false);
                replayed++;
            }
            return replayed;
        });
    }

    private IngestTask parse(String body) {
        try {
            // 消息由 Jackson2JsonMessageConverter 写入，结构是 {"docId":41,"traceId":"..."}
            var node = new com.fasterxml.jackson.databind.ObjectMapper().readTree(body);
            return new IngestTask(node.path("docId").asLong(), node.path("traceId").asText(""));
        } catch (Exception e) {
            return null;
        }
    }

    private String header(GetResponse response, String name) {
        Object value = response.getProps().getHeaders() == null ? null
                : response.getProps().getHeaders().get(name);
        return value == null ? "" : value.toString();
    }

    private Integer intHeader(GetResponse response, String name) {
        String value = header(response, name);
        try {
            return value.isBlank() ? null : Integer.parseInt(value);
        } catch (NumberFormatException e) {
            return null;
        }
    }

    public record DlqItem(String routingKey, long docId, int retryCount, String lastError) {
    }
}
```

`RabbitTemplate.execute(ChannelCallback<T>)` 的 lambda 允许抛 `IOException`；`basicGet/basicAck/basicNack` 都在 `com.rabbitmq.client.Channel` 上。`convertAndSend` 在回调里调用同一个 `RabbitTemplate` 会拿另一条 channel，不会和当前 channel 冲突。
